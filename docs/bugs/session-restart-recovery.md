# 会话过期与服务重启的恢复边界

本版本使用服务端随机凭证注册表，完整约定见 [会话说明](session-cookie-owner.md)。
旧签名方案及原排障说明保存在仓库外的本地废仓，Git 历史保持不变。

- 同一进程内：会话业务状态因空闲 TTL 清理后，仍有效的浏览器身份可以通过
  bootstrap 安全建立新状态。内部 HMAC 校验、所有者及状态代数检查继续保留；
  不接受其他用户的状态，不允许延迟回调覆盖已恢复的新状态。
- 进程重启后：凭证注册表、业务状态和内部随机校验材料全部重新建立。
  旧 Cookie 请求业务接口得到 401 和“重新打开首页”的提示。重新打开首页
  才取得新身份；不根据旧页面、IP 或遗留磁盘草稿推断身份。
- 未保存的图像、队列、拼接工作及跨重启草稿恢复不作保证。已有导出文件
  仍按原保留策略处理，不自动分配给新会话。
- 长任务、SSE 和上传下载的在途请求持有租约，清理无法确认任务已结束时
  保留归属。容量满返回 503，不挤出正在使用的浏览器。

测试必须区分同进程恢复与服务重启；内部状态防篡改、跨用户拒绝、IP 变化、
回调异常清理、旧 Cookie 失效和首页重新建立身份均需保留覆盖。
