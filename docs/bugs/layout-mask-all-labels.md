# 版图 mask：同层标注同时显示

## 行为

“版图 mask 提示分割”中的一张版图代表同一层。保存的 Label 是该层中的区域，
即使两个区域重叠，也不把它们解释为上下层。

- 点击“使用当前已保存版图 mask”后，自动载入全部已保存标注。
- 所有标注持续显示；直接点击或拖动画布中的标注即可调整它。
- 选中某个标注只决定编辑对象，不改变其他标注的可见性和变换。
- 这里不显示 Label 选择栏、层顺序、单层显示或交叠预览控件。
- “生成全部版图分割结果”仍将各标注的变换后 mask 分别作为 SAM3 提示，
  使用原始目标图像推理，为每个标注生成一个实例。
- 没有保存 Label 时，沿用完整版图 mask 的单实例流程。

“叠层预测”页面仍保留自己的层顺序和交叠预览功能。共享编辑器通过
`group_view.same_layer` 区分这两种用途。

## 同步和显示

编辑器请求只发送变换和标注编辑意图，不回传底图或 mask 的预览图片，
以免大图超过已有请求大小限制。请求大小限制保持不变。

服务端校验并提交变换后，返回包含版本和请求摘要的确认。客户端收到匹配确认后
显示“已同步”，并继续发送尚未同步的编辑；失败时保留本地编辑并显示失败原因。
确认消息本身不会再次提交变换或使正在运行的分割失效。

工具栏按编辑器实际宽度换行，其样式限定在 `.layout-editor` 内，避免 Gradio
其他自定义组件的同名 `.toolbar` 样式覆盖它。画布中的 Label 字号按显示尺寸计算。

## 复验

1. 上传真实目标图像，在“版图截图转掩码”保存版图，并保存两个有交叠且各有
   独立可点击区域的 Label。
2. 切回“智能图像分割”，选择“版图 mask 提示分割”，载入当前版图。
   无需选择 Label，两个标注都应显示。
3. 分别连续拖动两个标注。每次只有被拖动者的变换改变，另一标注始终可见；
   等待同步后再次拖动，不能出现同步超时或编辑不再提交。
4. 启动模型并点击“生成全部版图分割结果”，应产生两个 PVS 实例。
5. 分别使用 764×884 和 390×844 视口检查真实页面：无水平溢出，
   数值完整显示，按钮和编辑器均可操作。

相关自动回归覆盖默认载入全部标注、无 Label 回退、变换隔离、过期批次拒绝、
同步确认及失败、确认回传防循环、大图请求裁剪、Gradio 绑定，以及共享组件的
叠层功能契约。前端构建必须从本分支的组件 backend 导入，避免共享环境中的
editable 安装指向其他工作目录。
